Quick Overview

If you are coming from Danganronpa, Process of Elimination will feel like a familiar, darker cousin to the series you love. It trades the high-speed Class Trial debates for a tense, cerebral, and highly tactical murder mystery. Process of Elimination is a brutal, high-stakes mystery that prioritizes logical deduction over fast-paced action. It offers a sophisticated take on the "Locked-Room" subgenre, where your primary weapon isn't a silver tongue, but your ability to organize and utilize a massive, diverse team of investigators under extreme pressure.

Detective Gentleman

Your Detective Roster will at the start list only the base information for each Detective. To get expanded information you'll need to get Residual Thoughts found in stages. Each Residual Thoughts is represented by an item in the gallery, so if you're missing one then look at the item (or the skit name in brackets) and check the list below. If you make sure you get each Residual Thought on your run of the game then you'll be missing 5, 4 of which will come from post game chapter selecting, and the final one will come from getting all the other Residual Thoughts. Once you have all Residual Thoughts, view the Detective Roster and view each Detective to get this trophy.
