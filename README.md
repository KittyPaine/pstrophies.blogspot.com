# PSTrophyGuides — 100% Completionist & Trophy Guide Platform

A custom, high-UX web platform born out of pure trophy hunting passion. Built to solve the widespread issue of abandoned, outdated guides on major gaming sites—ensuring completionists always have access to real-time, ultra-accurate, and strictly chronological walkthroughs for evolving titles.

## 📖 Origin & Mission

PSTrophyGuides started after encountering abandoned guides for games with aggressive live-service updates like *Tom Clancy's Rainbow Six Siege* and *PAYDAY 2*. When game updates altered trophy requirements, existing walkthroughs quickly became obsolete.

Originally hosted on *TrueTrophies*, administrative bottlenecks and strict walkthrough team approval queues delayed critical content updates from reaching players. To eliminate these delays, this self-hosted platform was created to allow instant, frequent, and complete control over guide maintenance.

## 🎓 Self-Taught Developer Evolution

In September 2025, enrollment began in a college program for **Mobile and Web Development**. Leveraging optional class formats, theoretical coursework was bypassed in favor of hands-on, self-directed learning. 

Instead of building generic classroom assignments, practical coursework was directly channeled into improving this platform and building real-world tools:
- **Custom Site Architecture:** Transformed the platform using modern HTML5, CSS3, and DOM-manipulation techniques learned through live development.
- **In-Post Search Bar:** Engine built with raw JavaScript and DOM manipulation, allowing users to instantly filter walkthrough sections without page reloads.
- **Dynamic Trophy Tag System:** Developed a custom tagging feature to filter guides by missables, difficulty, and collectible types.
- **C# Video Game Backlog Tracker:** Pivoted a standard class movie catalog assignment into a dedicated C# desktop application designed specifically for game backlog management.

While formal studies ended in May 2026, continuous daily development, refactoring, and feature expansion remain the core driving force behind the platform.

## 🚀 Key Platform Features

- **Strict Chronological Routing:** Step-by-step physical map paths that account for backtracking loops, hidden zone triggers, and missables.
- **Live-Service Resilience:** Instant updates reflecting real-time game balance patches, trophy re-works, and DLC additions.
- **Clear Point-of-No-Return Warnings:** Explicit, unmissable callouts before irreversible story events.
- **Dual-Playthrough Architecture:** Clear separation between 100% collectible sweeps (Easy/Very Easy) and high-difficulty requirement guides (e.g., FOXHOUND / Hard mode boss strategies).
- **In-Page DOM Search & Tagging:** Instant client-side filtering for fast zone, item, and trophy lookups.
